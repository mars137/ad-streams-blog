# Hero Image Prompts for "Roads? Where We're Going, We Don't Need Roads"

Use these prompts with Midjourney, DALL-E 3, or Ideogram.

---

## Option A: DeLorean + Data Streams (recommended)

```
A DeLorean time machine from Back to the Future, parked in a modern data center corridor. The flux capacitor glows electric blue. Instead of fire trails, the car leaves behind glowing streams of data — blue and cyan light trails representing real-time data flowing forward. The dashboard shows SQL code on holographic displays. Cinematic lighting, teal and blue color palette, photorealistic, 16:9 aspect ratio, professional blog header quality.
```

## Option B: Terminal Window Time Travel

```
A terminal window floating in space, with glowing blue code streaming out of it like time-travel energy trails. The code transitions from old-school green-text Kafka/Spark configs on the left to modern clean SQL on the right. Stars and data streams in the background. Dark background, electric blue and cyan accents, minimalist sci-fi aesthetic, 16:9 aspect ratio.
```

## Option C: Before/After Split Screen

```
Split-screen image: left side shows a tangled mess of cables, servers, and infrastructure (warm red/orange tones, chaotic), right side shows a clean, minimal glowing blue cube representing a unified platform with data streams flowing into it smoothly (cool blue/cyan tones, serene). The divide between them has a lightning bolt or time-warp effect. Professional illustration style, 16:9, blog header.
```

## Option D: Minimalist Abstract

```
Abstract data visualization: six tangled red nodes on the left dissolving into one clean blue crystalline structure on the right. Data streams flow between them like time-travel trails. Dark navy background, minimalist geometric style, Snowflake brand blue (#29B5E8) as accent color. Clean, professional, suitable as a Substack hero image. 16:9 aspect ratio.
```

---

## Substack Dimensions
- Hero image: 1456 x 816 px (16:9) or wider
- In-post images: max-width 728px recommended
- Format: PNG or high-quality JPEG
